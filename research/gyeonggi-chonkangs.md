조사일: 2026-10-24
검색어: 경기도 촌캉스 숙소 / 경기도 촌캉스 / 촌캉스 숙소 추천 / 양평 촌캉스 / 가평 촌캉스
분석: 블로그 탭 상위 13개 글 + 자동완성 + 통합검색 AI 브리핑 질문

## 1. 사람들이 같이 찾는 키워드 (자동완성)
- 경기도 촌캉스 숙소 → 솥뚜껑 / 예약 / 내돈내산 / 10인 / 추천
- 경기도 촌캉스 → 독채 / 펜션 / 솥뚜껑 / 민박 / 체험 / 단체
- 양평 촌캉스 → 숙소 / 체험 / 펜션 / 애견동반 / 독채 / 단체 / 겨울 / 가성비 / 솥뚜껑
- 가평 촌캉스 → 숙소 / 솥뚜껑 / 펜션 / 독채 / 애견동반 / 민박 / 가성비

## 2. 통합검색 AI 브리핑이 묻는 질문 (= 글에 답이 있어야 할 섹션)
- 숙소는 어떤 시설과 공간 구성을 갖추고 있나요?
- 어떤 체험 프로그램이 있나요?
- 인기 있는 이유는?
- 주변에 함께 가볼 만한 곳은?
- 준비물은? / 숙소 고를 때 확인할 점은?

### 특징
- **해외 호텔 글보다 짧음**: 1,100~3,500자. 대신 사진·슬라이드가 많음.
- **수익 링크가 거의 없음**: 13개 중 OTA 링크는 아고다 1개뿐. 대부분 개인 펜션·민박이라 네이버예약·에어비앤비·자체 홈페이지·스마트스토어로 예약. → 내 숙소가 여기어때/아고다/트립닷컴에 있으면 경쟁 글 대비 수익화 여지가 큼. 없으면 수익 링크를 걸기 어려움.
- **'내돈내산/내돈내잠' 강조**: 협찬 글이 섞여 있어 진정성이 차별점.
- **제목 공식**: `경기도 촌캉스 숙소` + 지역(포천/안성/여주/양평/가평/화성) + 특징(한옥·독채·솥뚜껑·단체·가족·부부·생일파티) + 숙소명 + 내돈내산/후기
- **잘 먹히는 디테일**
  - 촌캉스 조끼·꽃무늬 옷 비치 여부 ("김장조끼 사지 마세요!" 같은 훅)
  - 솥뚜껑 삼겹살·바베큐 비용, 불멍
  - 요금 상세 (기본 인원, 인당 추가금, 바베큐 추가비)
  - 비치물품 목록, 주차, 체크인/아웃
  - 근처 시장 장보기 (예: 안성중앙시장), 주변 가볼 곳
  - 계절감: 지금은 가을·겨울 → 난방, 온돌, "겨울 촌캉스"

## 4. 글 구성안 (AI 브리핑 질문에 맞춤)
1. [이미지: 세시간전 제휴 표시] (수익 링크 있을 때)
2. 도입: 누구랑, 언제, 왜 촌캉스
3. 기본정보 박스: 위치(서울에서 거리/시간), 요금, 인원, 예약처, 체크인아웃, 주차 + 네이버 지도
4. ▼▼▼ 예약 링크 1차
5. 공간 구성: 마당 → 거실 → 방 → 주방 → 화장실
6. 비치물품 / 촌캉스 옷 / 준비물 체크리스트
7. 즐길 거리: 솥뚜껑 바베큐, 불멍, 체험 프로그램
8. ▼▼▼ 예약 링크 2차
9. 주변 장보기·가볼 곳
10. 장단점 + 이런 분께 추천 (단체/가족/커플/애견)
11. ▼▼▼ 예약 링크 3차
