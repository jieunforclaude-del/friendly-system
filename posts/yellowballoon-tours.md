🚌 PART 2. 노랑풍선시티투어 (서울 2층 시티투어버스)

[지도: 네이버 지도 '동대문디자인플라자' 장소 카드]

서울 시내를 2층 오픈버스로 도는 시티투어버스예요.
아이랑 서울 나들이, 외국인 친구 서울 구경, 야경 데이트로 많이 타더라고요.

⚠️ 헷갈리지 마세요!
서울시티투어버스는 운영사가 두 곳이에요.
노랑풍선시티버스 = 동대문디자인플라자(DDP) 출발
타이거버스 = 광화문 출발
예약 전에 어느 회사 코스인지 꼭 확인하세요.

1. 기본 정보

출발 장소 : 동대문디자인플라자(DDP) 앞 매표소 (밀리오레 맞은편)
예약 : 노랑풍선시티버스 공식 홈페이지 (온라인 예약 후 DDP 매표소에서 티켓 수령)
유아 : 48개월 미만 무료 (좌석 없이 보호자가 안고 탑승)

2. 코스별 가격 (2026년 일반 요금)

전통문화코스 주간 : 성인 27,000원 / 소인 20,000원
전통문화코스 야간 : 성인 22,000원 / 소인 18,000원
전통문화코스 + 케이블카 : 성인 40,000원 / 소인 31,000원

3. 전통문화코스 주간 (타고 내리고 자유롭게)

운행 : 첫차 09:30 ~ 막차 17:00 (DDP 출발 기준)
배차 : 평일 40분, 주말 25분 간격
노선 : DDP → 방산·중부시장 → 을지로3가 → 을지로입구 → 청와대 → 통인시장 → 광화문광장 → 서울역 → 남대문시장 → … 다시 DDP

✔ 운영 시간 안에서는 정류장에서 자유롭게 내렸다 다시 탈 수 있어요
✔ 늦은 오후 일부 회차는 몇몇 정류장을 그냥 지나가는 무정차 구간이 있어서, 내리고 싶은 곳이 있으면 일찍 타는 게 좋아요
✔ 가을엔 2층 오픈석에서 보는 남산 단풍이 명당이라 좌석이 빨리 찬대요
✔ 남대문시장은 주말에 사람이 너무 많아서 아이랑은 비추라는 후기도 있었어요

4. 전통문화코스 야간 (서울 야경 투어)

운행 : 1일 1회, 무정차 약 1시간 (DDP 출발·도착)
출발 시간 : 10월·11월 18:30 (월별로 다를 수 있어요)
✔ 야간은 온라인 사전 예약 필수
✔ 매표소에서 티켓 받으면 팔찌를 채워줘요
✔ 2층 좌석은 선착순이라 조금 일찍 가서 대기하는 걸 추천

5. 주차 꿀팁

DDP 근처 건물 주차장을 '모두의주차장' 같은 앱으로 미리 예약하면 편해요.
(후기 기준 밀리오레 6시간 8,500원, 두타 5시간 8,900원 / 2026년 10월)
