# 경기도 촌캉스 숙소 정보성 포스팅 초안

> 사용법
> - 정보성 글: "직접 가려고 찾아보고 비교한 글" 프레임. 묵어본 것처럼 쓰지 않기.
> - `[사진: ...]` = 넣을 이미지. **다른 블로그·숙소 공식 사진은 무단 사용 금지.** 대신 쓸 수 있는 것:
>   - 네이버 지도 장소 카드 (에디터 '장소' 버튼 → 숙소 사진이 자동으로 같이 뜸)
>   - 여기어때 링크 카드 (썸네일 자동 표시)
>   - 직접 만든 이미지 (표지, 비교표, 체크리스트를 미리캔버스 등으로)
> - `**▼▼▼ 문구 ▼▼▼**` 바로 아래 `[링크: ...]` = 세시간전 링크 자리
>   - 여기어때 확인됨: 하늘밭펜션, 아그니초시매 한옥스테이, 취옹예술관 (하늘밭은 아고다에도 있음)
>   - 나머지는 OTA에 없음 → 링크 없이 예약 방법만 안내
>   - ⚠️ 세시간전에서 여기어때 국내 숙소 링크가 되는지 확인 필요
> - 가격·조건은 2026년 9~10월 블로그 후기 기준. 바뀔 수 있으니 본문에 "예약 전 확인" 문구 유지.
> - `[직접 입력: ...]` = 본인 이야기 (선택)

[지도: 네이버 지도 '꼬순이네민박' 장소 카드]

| 항목 | 내용 |
|---|---|
| 위치 | 경기 여주시 점동면 어우실길 77-5 |
| 입실/퇴실 | 14:00 / 12:00 |
| 인원 | 2인 |
| 반려견 | 12kg 이하 최대 2마리 무료 |

✔ 저수지 앞 친환경 황토집 원룸
✔ ⚠️ **바베큐·실내 조리 불가** (포장 음식은 OK). 대신 불멍 가능 (장작 10kg 2만 원)
✔ 마당 자전거로 저수지 둘레길 산책

### +1. 옥란재 (화성) — 3대가 함께 가는 프라이빗 한옥

[지도: 네이버 지도 '옥란재' 장소 카드]

| 항목 | 내용 |
|---|---|
| 위치 | 경기 화성시 서신면 영종이길 120-8 |
| 입실/퇴실 | 14:00 / 11:00 |
| 예약 | 네이버 예약 |
| 유료 옵션 | 바베큐 그릴+숯(10인) 2만 / 벽난로 2만 / 캠프파이어 3만 |

✔ **2만 평 정원**에 한옥, 연못, 숲. **한 팀만** 받는 구조
✔ 독채는 평일 운영, 전체 대관은 최대 20인
✔ 생수 미제공, 욕조 없음. 근처 궁평항에서 갯벌체험 + 장보기 코스
