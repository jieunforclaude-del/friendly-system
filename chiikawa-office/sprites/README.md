# 캐릭터 그림 넣는 곳

여기에 PNG를 넣으면 손그림 대신 그 그림이 나와요. 새로고침만 하면 바로 바뀌어요.

| 파일 이름 | 누구 |
|---|---|
| `chiikawa.png` | 치이카와 |
| `hachiware.png` | 하치와레 |
| `usagi.png` | 우사기 |
| `shisa.png` | 시사 |
| `rakko.png` | 랏코 |
| `kurimanju.png` | 쿠리만쥬 |

자세별로 따로 넣고 싶으면 `이름-자세.png` 로 저장하면 그 자세일 때만 그 그림이 쓰여요.
(없는 자세는 기본 그림 사용)

| 자세 | 언제 |
|---|---|
| `-type` | 파일 수정·터미널 (타자) |
| `-read` | 파일 읽기·검색 (책 읽기) |
| `-sit` | 생각 중 |
| `-raise` | 허락 기다림 (손 들기) |
| `-jump` | 일 끝남 (만세) |
| `-sleep` | 소파에서 낮잠 |
| `-walk` | 걷기 |

예: `usagi-jump.png`, `chiikawa-sleep.png`

### 한 장에 몰아서 (시트)

`chiikawa-sheet.png` 처럼 `-sheet.png` 로 저장하면, 한 장에 가로로 나란히 그린 4가지 자세를 알아서 잘라 써요.
순서: **기본 · 낮잠(sleep) · 만세(jump) · 손들기(raise)** — 캐릭터 사이를 띄워서 그려야 잘 잘려요.

- 배경은 꼭 **투명**이어야 해요 (흰 배경이면 네모 박스가 보여요)
- 발이 그림 맨 아래에 닿게, 정면을 보는 전신 그림이 제일 잘 어울려요

## 배경·가구

| 파일 이름 | 무엇 | 팁 |
|---|---|---|
| `background.png` | 방 전체 배경 | 가로로 긴 그림. 위 30%는 벽, 아래는 빈 바닥, 왼쪽 벽에 문 |
| `desk.png` | 책상 (6개 모두 같은 그림) | 정면, 낮고 넓게(가로:세로 약 3:1), 노트북은 오른쪽 끝에 |
| `sofa.png` | 소파 | 정면, 가로로 긴 3인용 |
| `plant.png` | 화분 | 정면 |

배경 말고는 모두 투명 배경이어야 해요. 배경 그림이 있으면 창문·시계·러그 같은 기본 손그림은 안 나와요.
